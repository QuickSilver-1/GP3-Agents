## 🚀 Описание проекта

Проект представляет собой **AI-агента для анализа данных**, который автоматически проходит полный цикл работы с датасетом:

1. Анализ данных  
2. Объединение датасетов  
3. Очистка данных  
4. Формирование бизнес-выводов  
5. Визуализация  
6. Построение ML-модели  
7. Генерация отчёта  

Агент построен на базе **LangGraph + LLM (OpenAI)** и умеет:
- вызывать инструменты (tools)
- сохранять и извлекать знания из **долгосрочной памяти (Weaviate)**
- динамически создавать новые инструменты
- работать с Excel-файлами

---

## 🧠 Ключевые возможности

### 🔹 1. LLM-оркестрация (LangGraph)

Агент реализован как граф состояний:

С поддержкой:
- tool calling  
- conditional routing  
- memory integration  

---

### 🔹 2. Долгосрочная память (Weaviate)

Агент умеет:
- сохранять знания (`FACT`, `RULE`, `CONTEXT` и т.д.)
- фильтровать по важности (`LOW → CRITICAL`)
- делать semantic search по памяти  

---

### 🔹 3. Динамические инструменты

Есть встроенный tool:

Позволяет агенту:
- генерировать Python-функции  
- автоматически регистрировать их как инструменты  
- использовать их дальше в пайплайне  

---

### 🔹 4. Работа с данными

- Загрузка: Excel (`raw`)  
- Сохранение: Excel (`processed`)  
- Работа через `pandas`
